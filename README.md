Ответ Сервера – результат авторизации
Преамбула	Адрес + Спецификатор	Номер	Длина	Данные	CRC
0х24	        0x63	            0x65	0х000B	11 байт	1 байт

Тип данных:
Device ID (DID) 	10 байт char	
Результат авторизации	1 байт  	код	Расшифровку см. ниже 

Результат авторизации:
0x01 - авторизовано;
0х02 - ошибка при расшифровке поля с данными;
0x03 - ошибка комбинации спецификатора и номера;
0x07 - ошибка целостности (поля «CRC»);
0x0A - ошибка авторизации.
