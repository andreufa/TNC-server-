Структура сообщений протокола взаимодействия МП РОС и модуля связного с АПК
Преамбула (1 байт  - символ $)	Адрес	+  Спецификатор ( 1 байт)	Номер команды ( 1 байт)	Длина данных ( 2 байта)	Данные (N байт)	CRC ( 1 байт)

uint8_t	uint8_t	uint8_t	uint16_t	char[]	uint8_t

Отправляемые с устройства сообщения на сверер  - это команды, поэтому  Адрес + Спецификатор = 0х70
Номер команды пока установим 0х65 для первой команды серверу , когда устройство сообщает свой ID

Ответ сервера по такой же структуре, но Адрес + Спецификатор = 0х73

При отправке устройством второго сообщения( с подписью)  - номиер команды 66, Адрес + Спецификатор = 0х70

При ответе сервера на эту команду Спецификатор = 0х73

Сделай по такому протоколу обмен.
