##  ➕ Добавление нового устройства
Чтобы зарегистрировать новое устройство в системе:

Найдите блок «Добавить устройство» на главной странице.

Заполните поля:

Device ID — уникальный идентификатор (только латиница, цифры, без пробелов).

Пароль.

Опционально: если устройство должно быть сразу включено в обслуживание, установите галочку «В обслуживании».

Нажмите кнопку «Добавить».

### Проверьте:
В таблице устройств должна появиться новая строка с вашим ID и соответствующим статусом.

⚠️ Важно:
Device ID должен быть уникальным. При попытке добавить существующий ID система либо выдаст ошибку. Рекомендуем сначала проверить список уже зарегистрированных устройств.

## 🔄 Управление статусами
➜ Перевести в режим «В обслуживании»
При добавлении: просто поставьте галочку «В обслуживании».

Для уже существующего устройства:
Нажмите кнопку «Деактивировать» в колонке «Действия» напротив нужного устройства.
Статус изменится на «Отключено», и устройство потеряет возможность авторизации на сервере.

➜ Вернуть в режим «Эксплуатация»
Если устройство находиться в режиме "Отключено" и вы хотите вершнуть его в эксплуатацию - нажмите кнопку "Активировать".


## 🔑 Смена пароля устройства
Если нужно изменить пароль для подключения устройства:

В строке с устройством найдите поле «Новый пароль».

Введите новый пароль (соблюдайте требования надёжности).

Нажмите кнопку «Сменить пароль».

Дождитесь подтверждения — уведомление об успешном изменении появится в интерфейсе или логах.

⚠️ Важно:
После смены пароля все подключённые клиенты (устройства или сторонние сервисы) обязаны использовать новый пароль. Старые сессии могут продолжать работать до истечения токена или времени жизни сессии.

## 🏷️ Смена Device ID
Если устройству нужно присвоить новый уникальный идентификатор:

В строке устройства найдите поле «Новый ID».

Введите новый идентификатор (латиница, цифры, без пробелов).

Нажмите «Сменить ID».

Проверьте:
В таблице ID должен обновиться, а статус и дата регистрации остаться прежними.

### ⚠️ Осторожно!
Смена ID может нарушить работу внешних интеграций, скриптов и правил маршрутизации. Если этот ID используется в других системах — обязательно обновите его вручную во всех связанных сервисах.

## 🗑️ Удаление устройства
Удаление — это необратимая операция. Используйте её только в крайнем случае.

Напротив нужного устройства нажмите красную кнопку «Удалить».

Если появится диалог подтверждения — подтвердите действие.

Убедитесь, что строка с устройством исчезла из таблицы.
### ⚠️ Осторожно!
Удаление устройства приведет к тому, что в дальнейшем будет не возможно зарегистрировать устройство с этим ID.
Если нужно временно отключить устройство — используйте статус «Деактивировать», а не удаление.

# Инструкция по подключению к TCN-Server по TCP
Сервер работает по протоколу TCP с обменом JSON-сообщениями, разделёнными символом новой строки (\n) . Устройство подключается, проходит рукопожатие (handshake), после чего может отправлять сообщения, которые будут ретранслированы (broadcast) всем другим подключённым клиентам.

Устройство должно установить TCP-соединение с сервером.

Сразу после установки соединения устройство обязано отправить JSON-строку с параметрами авторизации, завершённую символом \n (перевод строки). 
Пример сообщения запроса на авторизацию:
{
"protocol": "progress_konsul_bin",
"lsncmd": "104",
"deviceId": "1-07-77-1-1",
"password": "currentPassword"
}
При успешной авторизации, сервер отправит ответ:
Msg104Ok
При ошибке сервер отправит ответ:
Msg104Denied

## Рассылка широковещательных сообщений
После успешной авторизации, устройство может отправлять сообщения, которые будут транслироваться всем подключенным устройствам.
