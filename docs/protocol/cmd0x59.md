    Сообщение 0x59 передает посчитанные ошибки времени излучения опорных
    станций (приведенные к метрам), которые нужно применять на АТ для
    решения навигационной задачи в точке с неизвестными координатами.

    1.  Команда управления -- отправляет текущие ошибки времени
        излучения опорных станций (приведенные к метрам).
