## Контекст:
Сервер работает по TCP соединению с устройством
На устройстве STM32
## Какая логика должна быть:
Устройство устанавливает TCP соединение с сервером. После установки соединения отсылает серверу свой ID
Сервер получает ID устройства, формирует случайную 8 байтовую последовательность
Формирует сообщение - 8 байтовая последовательность + timestamp
Устройство своим приватным ключем шифрует полученную 8 байтовая последовательность + timestamp и отправляет ID + зашифрованное сообщение серверу. Сервер расшифровывает публичным ключем полученное шифрованное сообщение, сравнивает с отправленным и если все ОК  - отвечает "Success" иначе "Denied"

Любое сообщение начинается с $, затем идет длина сообщения, чтобы сервер и клиент значли сколько байт читать, затем сами данные

## Задача:
Подобрать алгоритм шифрования, чтоьы STM32 справилось с ним.
Рекомендовать каким образом создать публичный и приватный ключ
Написать код для сервера на golang
Написать код для клиента на golang (для тестирования сообщения)


## Ответ 

### 1. Генерируем приватный ключ (для STM32)
openssl genrsa -out atb_private_key.pem 2048

### 2. Извлекаем публичный ключ (для сервера)
openssl rsa -in atb_private_key.pem -pubout -out atb_public_key.pem

### 3. Конвертируем приватный ключ в DER для прошивки STM32
openssl rsa -in atb_private_key.pem -outform DER -out atb_private_key.der

### 4. Конвертируем DER в C-массив для встраивания в прошивку
xxd -i atb_private_key.der > atb_private_key.h
